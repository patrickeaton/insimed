# Planning docs

This directory holds the planning artifacts the skills produce and read:

- **Pitches** (`<slug>-pitch.md`) — Shape Up pitches from `/create-a-pitch`
- **PRDs** (`<name>.md`) — product requirement docs from `/write-a-prd`
- **Plans** (`<feature>.md`) — phased implementation plans from `/prd-to-plan`

These docs are **committed to the repo** so they can be reviewed by the team.
The skills (`grill-me`, `do-work`, etc.) use whatever lives here as the source
of context for a piece of work — there is no external issue tracker.

Typical flow: `create-a-pitch` → `grill-me` → `write-a-prd` → `prd-to-plan` → `do-work`.
