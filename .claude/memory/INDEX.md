# 🧠 InSim Second Brain — Index

The project's persistent, repo-committed knowledge base. It lets InSim accumulate
context about the business, its projects, and its decisions so each session starts
informed instead of cold.

> Last updated: 2026-06-03

## How to use this

- **Before working:** skim this index, then open the topic files relevant to your
  task. Treat stored facts as background context.
- **After learning something durable** (a business fact, a decision, a project
  detail that will matter later): capture it here. See the `second-brain` skill.
- **Keep it lean:** store facts, not transcripts. Merge, don't duplicate. Date
  decision-log and open-question entries.
